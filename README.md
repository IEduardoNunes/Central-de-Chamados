# Central de Chamados

Sistema em Python para gerenciar chamados de suporte técnico: registra solicitações, identifica usuários e analistas e guarda a conclusão de cada atendimento.

## Funcionalidades
- Cadastro de solicitações de suporte
- Identificação do usuário solicitante e do analista responsável
- Registro da conclusão de cada atendimento
- [Listagem / busca de chamados, se existir]

## Tecnologias
Python

## Como executar
1. Clone o repositório
   ```bash
   git clone https://github.com/SEU-USUARIO/central-de-chamados.git
   cd central-de-chamados
   ```
2. Execute o programa (requer Python 3.x)
   ```bash
   python main.py
   ```

> **Observação:** nesta versão os dados ficam armazenados em memória, ou seja, não persistem depois que o programa é fechado. [Confirme se isso vale para o seu projeto e ajuste.]

## Aprendizados
- Lógica de programação aplicada a um fluxo real de atendimento (abertura → atendimento → conclusão)
- Organização de dados de usuários, analistas e chamados no código
- Inspiração direta no fluxo de um sistema de chamados que uso profissionalmente em ambiente hospitalar
